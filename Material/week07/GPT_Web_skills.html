02 / THE DIFFERENCE

同樣一句話。
不同的工作方式。

以網拍商品文案為例，兩者並不互相取代，而是互相搭配。

PROMPT / 單次指令

這次，
請幫我完成。

適合臨時交辦。下次換一件商品，可能得重新說明規則。

「幫我寫一篇新款襯衫的 IG 文案，要活潑一點。」
SKILL / 可重複的方法

以後這類工作，
請照這套方法。

適合經常重複、品質需要一致的工作。

先讀商品資料 → 確認缺少的資訊 → 按品牌語氣撰寫 → 檢查不實宣稱 → 提供兩個版本。

06 / GOOD QUESTIONS
在你開始之前，
可能還想知道⋯
Skill 一定要會寫程式嗎？
不一定。像文案、備課或文件整理的 Skill，起點可以只是清楚的文字規則。涉及操作系統或自動化工具時，才可能需要額外設定。
Skill、Prompt、Agent 到底差在哪裡？
Prompt 是當下交辦的指令；Skill 是一類任務的可重複方法；Agent 是能規劃、調用工具並執行任務的系統。Agent 可以使用 Skill，但三者不相同。
Skill 寫好後就不會出錯了嗎？
不會。Skill 能讓步驟較一致，但無法保證事實正確。重要資訊仍應檢查來源、權限與最終輸出。
每件事都要做成 Skill 嗎？
不用。一次性的探索需求，先正常與 AI 對話即可。重複出現、有固定做法和品質標準的工作，才更值得整理成 Skill。
