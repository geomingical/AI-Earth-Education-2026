A FAMILIAR WAY TO THINK ABOUT IT

像把你的食譜，
交給一位廚師。

「請做一道菜」是這次的要求。食譜則記錄材料、步驟與火候，讓下次做同一道菜時，有一套方法可循。

Skill 也是如此。你把在意的做法寫清楚，AI 在需要時拿來參考，不必每次從頭交代。

類比的界線：有食譜不保證每道菜都成功。AI 也可能誤解或漏做，所以結果仍要核對。

依產品說明加入 Skill。用不同例子測試，根據實際結果調整指南。

打開一個 Skill，裡面長什麼樣？

依 Agent Skills 格式，一個 Skill 是一個資料夾，必須包含 SKILL.md。它記錄名稱、用途與完整指示；範本、參考資料和程式都是選配。

# 會議紀錄整理

1. 先閱讀完整內容，分開列出決議與待辦。
2. 每項待辦列出任務、負責人、期限。
3. 原文沒有提供的資訊，標記「待確認」。
4. 不把建議寫成已通過的決議。
5. 完成後逐項對照原文，列出需要使用者確認的問題。

下載後，依你使用的 AI 產品說明加入 Skill。貼進一般聊天視窗，不代表已完成安裝。

AI 會自動知道要用哪個 Skill 嗎？

支援的 AI 工具通常會先讀取各個 Skill 的名稱與用途，再根據任務載入完整指示；你也可以明確指定。實際觸發方式依產品而異，並不保證每次都選對。

為什麼不把所有指南一次交給 AI？

AI 一次能處理的內容有限。先讀名稱與用途，遇到相關任務再載入完整指南，有助於把當下的內容留給需要的資訊。這稱為漸進載入。
